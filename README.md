# LLM-Eval-Lab

LLM-Eval-Lab｜大模型评测与回归测试

## 项目背景

面向中英文技术问答、代码辅助和专业知识问答，设计一套可复现的大模型评测系统，对比不同模型在任务质量、响应延迟和调用成本上的表现。

项目重点包括评测数据集构建、自动评分与人工校准、多模型对照实验，以及模型版本和提示词变更后的回归测试。通过记录完整的评测配置和实验结果，分析模型之间的性能差异、常见失败类型及其原因，最终形成有数据支撑的模型选型报告。

配套项目 gitlab-handbook-rag 使用 GitLab 公开手册构建知识库问答应用，进一步研究文档切分、检索参数和生成策略对实际问答质量的影响。
